# Logo usage rules

## Approved files
Maintain the canonical set in a single source (DAM / Figma library). Anything else is unauthorized.
- SVG primary (color, on-light)
- SVG inverse (color, on-dark)
- Monochrome (single color)
- Single-color outline (where flat fills won't print)

## Clear space
Minimum clear space = the height of <X> (typically the cap-height of the wordmark, or the width of a key letter). NO content, edge, or seam may sit inside this space.

## Minimum size
- Digital: <N>px height
- Print: <N>mm height
Below these sizes use the simplified mark variant.

## What you may NOT do
- Stretch / squish (preserve aspect ratio always)
- Recolor outside the approved palette
- Add effects (shadow, glow, outline, gradient) unless documented
- Place on busy backgrounds without the safe-zone treatment
- Crop / partial-show as decoration (logo is not a pattern)
- Use the wordmark and lockup interchangeably — they're different artifacts

## On photography
- Place on the area of lowest detail and highest contrast
- Use the inverse variant when the background is darker than ~50% luminance
- Add a subtle scrim if no clear zone exists — never paste over a busy region
