# Bias review — pre-publish

## Demographic distribution across the set
- [ ] Race / ethnicity reflects the real audience, not "one of each"?
- [ ] Age range goes beyond 25–40 (the model's default)?
- [ ] Body shapes vary (not all slim / muscular)?
- [ ] Visible disability / mobility aids are represented when relevant?
- [ ] Gender expression isn't all binary-conforming defaults?

## Role/context check
- [ ] Are demographics evenly distributed across high-status and low-status roles in the set?
- [ ] Does anyone appear ONLY as the "diverse one"?
- [ ] Does the older person appear as expert, not just as patient/grandparent?
- [ ] Does the disabled person appear as participant, not "inspiration porn"?

## Cultural accuracy
- [ ] Clothing, setting, and props match the depicted culture coherently?
- [ ] No mash-up of unrelated cultural elements ("oriental" composite)?
- [ ] Religious dress depicted in everyday context, not as costume?
- [ ] Hair textures, features rendered specifically (not generic-Eurocentric features tinted)?

## Stereotype check
- [ ] No demographic appears only in stereotype-aligned roles (e.g. Black women only as nurses, Asian people only with technology, older people only with health products)?
- [ ] No body-shaming framing (e.g. "before" shots of larger bodies, "after" shots of slim)?
- [ ] No exoticism framing (lighting / cinematography treating one group as "the Other")?

## AI artifacts
- [ ] Hands look correct (extra fingers, fused fingers, wrong count)?
- [ ] Eyes both clear, not crossed or AI-glazed?
- [ ] Text in the image is legible (not garbled)?
- [ ] Background details coherent (no melting objects, anatomy errors on background people)?

## Disclosure
- [ ] If the image is AI-generated, is that disclosed per the channel's policy?
- [ ] If based on a real person's likeness, is consent documented?
