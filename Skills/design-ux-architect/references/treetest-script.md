# Tree test (5 users, 30 min total)

## Setup
- Create the tree (your candidate IA) in Optimal Workshop / Maze / a Google Doc with collapsible bullets.
- Write 5–8 tasks framed as goals, NOT as your nav labels.
  - Good: "You want to change the email address linked to your account."
  - Bad: "Go to Settings → Profile → Account."

## Protocol per user
1. (1 min) Explain: "I'll show you a list. Tell me where you'd look — no right or wrong."
2. (3–4 min) Read each task aloud; user clicks through the tree; you note where they go.
3. (1 min) Ask: "Where did you expect to find this? What label did you look for?"

## Read the results
- **First-click success** is the strongest signal — if users don't pick the right branch first time, the label is wrong.
- **Completion success** matters less; people backtrack.
- **Multiple users picking the SAME wrong path** = your label belongs in their wrong branch.

## Fix
- Rename to user-language labels.
- Move items if 3+/5 users put them somewhere else.
- Re-run on 5 more users after changes. Tree tests are cheap; do it twice.
