# Moderated usability test — script + note template

## Before
- Tasks written as goals, not clicks (3–5 tasks, 45 min total).
- Prototype / staging URL ready; reset state between users.
- Recording consent in writing.
- Observer in a second room or muted; one moderator only.

## Moderator script (intro, ~3 min)
> "Thanks for joining. We're testing the design, not you — if anything is confusing, that's a problem with our design, not with you. There are no right answers. Please think out loud as you go: what you're looking for, what you expect to happen. I might ask follow-up questions but I won't help you, because I want to see where the design needs work."

Per task:
> "Imagine you want to <goal>. Show me how you'd do that."
- Stay silent while they explore. Note hesitation, backtracks, surprises.
- If stuck >60s: "What are you thinking?" — not a hint.
- Never explain the UI mid-task.

After each task:
- "On a scale 1–5, how easy was that?" (SEQ — Single Ease Question)
- "What surprised you?"

End:
- "What worked well?"
- "What would you change?"
- "Anything we didn't ask about?"

## Observer note template
```
User: <id>   Task: <name>
Outcome: ✅ completed / ⚠️ completed with struggle / ❌ failed
Time: <s>
Hesitation points: <where + what they said>
Quotes: "..."
Errors: <wrong path taken>
SEQ: <1–5>
```
