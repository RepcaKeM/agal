# Data-ink cleanup (Tufte-style)

For any chart, walk through this list and delete:

- [ ] Gridlines (or fade to lightest possible)
- [ ] Chart border / box
- [ ] Tick marks (replace with light reference lines if needed)
- [ ] Background fill / 3D / shadow / gradient
- [ ] Legend (direct-label the series instead, when ≤4)
- [ ] Decorative axis titles ("Year" on a time axis is obvious)
- [ ] Currency repeated on every label (put it in the axis title once)
- [ ] Decimal precision beyond what matters (round 1.247 → 1.2)

For any slide:
- [ ] Logo / footer / page number on every slide (keep only when needed)
- [ ] Bullet-list filler ("Key drivers", "Strategic initiatives") that says nothing
- [ ] "Confidential" stamp covering the content
- [ ] Stock photos of diverse people pointing at laptops

## What to KEEP
- Title (the insight, full sentence)
- The data
- One annotation that says "look here"
- Source line (small, bottom-left)
