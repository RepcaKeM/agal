# Whimsy surfaces — examples

## Empty states

❌ "No items"
✅ "Nothing here yet. Drop a file or paste a link — we'll take it from there."

The empty state explains what to do next AND has a beat of voice.

## Error messages

❌ "An error occurred. Please try again."
✅ "We couldn't save that — your text is still here, no rush. Try once more, or copy it somewhere safe and we'll dig into what happened."

Useful first, warm second. The user wants to know they didn't lose work.

## Loading / waiting

❌ Generic spinner with "Loading…"
✅ Specific to context: "Looking through 4,237 messages — give us a sec." Or just a beautifully tuned spinner that matches the brand without text.

## Success confirmations

❌ "Saved!"
✅ "Saved — 3:47pm." (Quietly specific. User knows exactly when.)
or
"First invoice sent. That's a real one — not a test."

## First-run / onboarding

❌ "Welcome to ProductName!"
✅ "Hey — first time here? Let's get you something live in 2 minutes." (Acknowledges first-run state; promises something concrete.)

## Easter eggs

Konami code on the homepage gives you a small joke; finding it requires curiosity. Don't advertise easter eggs; the discovery is the reward.

Rules for easter eggs:
- Discoverable but not in the way
- Don't change product state
- Don't repeat after first discovery (or repeat only once per session)
- Skippable / un-triggerable with the same input

## Empty / loading / error — the unholy trinity
These three surfaces are where 90% of products go cold. Every product team should write personality into them once and audit annually.
