# Channel specs — length, hook, format

| Channel | Length | Hook style | Format |
|---|---|---|---|
| **Blog post** | 800–2500 words | Headline + first 2 sentences answer "why read this now" | H2/H3 subheads, code/quote callouts, single CTA |
| **Newsletter** | 300–800 words | Personal voice; specific subject line | Short paragraphs, one idea, one link |
| **LinkedIn post** | 1200–3000 chars | Bold opening line; line breaks; pattern interrupt | First 2 lines visible; rest behind "see more" |
| **X / Twitter** | 1 tweet or thread | Number / specific noun in tweet 1 | Thread: tweet 1 = hook, last tweet = ask |
| **Long-form video (YouTube)** | 8–15 min | First 15 sec = the promise + chapter preview | Pattern interrupts every 90 sec |
| **Short video (Reels/Shorts/TikTok)** | 15–60 sec | First 2 sec = hook (motion + audio) | Subtitles burned in; tight cuts |
| **Podcast episode** | 25–60 min | Cold open with the punchiest moment | Show notes with timestamps |

## Universal rules
- Headline / subject line / tweet 1 is 50% of the work. Iterate until it sings.
- Test 2–3 variants of the hook before committing to one.
- Match the platform's native form; cross-posted screenshots get ignored.
