| Q3 | hub | … | | | | | |

## Mix targets
- 1 hero piece per quarter (big bet, long-form, multi-format)
- 1–2 hub pieces per month (depth on a sub-topic)
- 1–2 hygiene pieces per week (search-driven, always-on, evergreen)

## Stage SLAs
- Brief approved → draft owner has 10 days to draft
- Draft → edit pass within 3 days
- Edit → publish within 5 days
- Slipped > 7 days from publish target = re-plan or descope
