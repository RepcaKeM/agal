# Repurpose tree — one core asset → many derivatives

## Core: 45-min webinar / podcast / talk

Repurpose:
- **Blog post** (2000 words) — the talk's argument written as prose. Embed the video.
- **Email summary** (400 words) — 3 takeaways + link to the video.
- **LinkedIn carousel** (8–10 slides) — one slide per key point.
- **X thread** (8–12 tweets) — the talk's outline.
- **3 short videos** — each clip = one quotable moment.
- **Quote graphics** (4–6) — for Instagram / LinkedIn one-offs.
- **Sales-enablement deck** — if relevant.

## Core: Long-form research / whitepaper / data report

Repurpose:
- **Executive summary** (1-page) — the chart + the 3 numbers + the takeaway.
- **Blog post per finding** (3–5 pieces) — depth per finding.
- **Infographic** — top 5 numbers visualized.
- **Webinar** — present the findings, take Q&A. (Now you can repurpose the webinar too.)
- **Press pitch** — angle for trade press based on the single most newsworthy finding.

## Pacing
- Publish the core first; schedule derivatives over the next 4–6 weeks.
- Don't dump everything in one week — you compete with yourself.
