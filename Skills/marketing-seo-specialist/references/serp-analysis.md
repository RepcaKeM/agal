# SERP analysis — 5 minutes per query

## Step 1: Look at the top 10 organic results (incognito)

Note:
- **Format**: blog article / product page / video / calculator / tool / list
- **Depth**: word count range (Ahrefs / SurferSEO will surface this fast)
- **Domain types**: brand sites / publishers / Wikipedia / Reddit / YouTube

## Step 2: Note SERP features

- Featured snippet (paragraph, list, table)?
- People Also Ask (PAA)?
- Video carousel?
- Image pack?
- Local pack?
- Knowledge panel?
- AI overview / SGE?

Each feature changes what "rank #1" actually means. Featured snippet steals the click; ranking #1 below a snippet is worth less.

## Step 3: Intent diagnosis

- **Informational**: top results are how-to / explainers
- **Navigational**: top result is a brand
- **Commercial investigation**: top is "best X for Y", comparison, review
- **Transactional**: product pages, "buy", price-comparison

If you write an explainer for a transactional query, you won't rank. Match.

## Step 4: Decide

- **Match the dominant format** OR have a clear reason to differ ("everyone ranks listicles, we rank with a tool").
- **Hit the depth** the top 5 average, or beat it with sharper specificity.
- **Cover PAA topics** in your subheads to be eligible for those features.
