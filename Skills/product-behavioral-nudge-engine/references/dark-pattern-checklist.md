# Dark-pattern checklist — what NOT to design

## Patterns to refuse

| Pattern | What it does | Why it's bad |
|---|---|---|
| **Forced action** | "Must opt in to continue" | Removes consent; trains users to dismiss |
| **Misdirection** | Bright CTA for one path; quiet "no thanks" | Manufactures consent |
| **Confirmshaming** | "No, I don't want to save money" | Manipulates via shame |
| **Roach motel** | Easy in, hard out | Cancellation friction kills trust permanently |
| **Privacy zuckering** | Defaults to max sharing | Violates informed consent |
| **Hidden costs** | Revealed at last step | Sunk-cost manipulation |
| **Sneak into basket** | Auto-added items / addons | Bait & switch |
| **Forced continuity** | Trial → silent paid subscription | Predatory across vulnerable populations |
| **Disguised ads** | Ad styled as content | Trust erosion |
| **Bait & switch** | Pricing changes after action started | Same as hidden costs, sharper |
| **Friend spam** | Imports contacts and emails them as the user | Reputation loss for the user |
| **Confirmshaming downgrade** | "Are you sure? You'll miss out on…" with guilt | Same as confirmshaming |

## Litmus tests

- **The "explain it" test**: if you described the mechanism plainly to a new user, would they consent?
- **The "loved one" test**: would you be comfortable if a family member encountered this design?
- **The "regulator" test**: if this came up in a regulatory inquiry, what would the headline read?

If any answer is uncomfortable, redesign.

## The harder case: ambiguous patterns

Some mechanics are not inherently dark but can become so:
- **Streaks**: motivating for users with intrinsic interest; coercive for users hooked on the streak alone
- **Variable rewards**: appropriate in games; corrosive in productivity tools
- **Social proof**: honest when accurate; manipulative when invented or inflated
- **Scarcity / urgency**: honest when real ("3 left in stock"); fake-scarcity is a dark pattern

Rule: the mechanic must be honest and the user must benefit from it as much as the business does.
