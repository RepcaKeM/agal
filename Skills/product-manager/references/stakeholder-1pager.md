# Decision 1-pager (Amazon-style narrative for exec sign-off)

## Title
A clear, declarative sentence — the decision being asked, not the topic.
> "Proposal: replace the legacy ratings engine with a managed service by Q3."

## Context
3–5 sentences. The current state, what changed, why we're at a decision point now.

## Options considered
| Option | Pros | Cons | Cost | Time |
|---|---|---|---|---|
| Do nothing | | | | |
| Option A | | | | |
| Option B (recommended) | | | | |

## Recommendation
The chosen option, in one paragraph. The named trade-off ("we accept higher per-call cost in exchange for offloading on-call burden").

## Risks & mitigations
| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|

## What we need
A specific ask — funding, headcount, sign-off — and the deadline by which a "no decision" becomes "no."

## Appendix
Data, deeper analysis, prior conversations. Anything that would clutter the main page.
