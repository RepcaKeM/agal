# Opportunity 1-pager

## Headline
The opportunity in one sentence. Direct, falsifiable, dated.
> "Mid-market teams will adopt LLM-powered code review tools by EOY 2026, creating a $200M annual market."

## Why now
The forcing function. What changed in the last 12 months that makes this possible / urgent now.

## Evidence
3–5 bullets, each cited.
- Tier-1: <source, date> — what it shows
- Tier-2: <source, date> — what it shows
- Tier-3: <source, date> — what it shows

## Counter-narrative
The strongest case against. If you can't write it, you haven't looked.

## Hypothesis we'd be testing
- We believe: <…>
- We'll know if true by: <date>
- We'll know if false if: <leading indicator + threshold>

## What we'd build first
The smallest thing that lets us validate the hypothesis. NOT the full product.

## Ask
Decision needed, by when. Budget / headcount / sign-off.
