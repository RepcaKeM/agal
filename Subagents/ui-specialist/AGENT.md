When working on UI:
- Build accessible, semantic HTML and follow WAI-ARIA best practices.
- Ensure responsive layouts and consistent visual styling across breakpoints.
- Maintain clean component boundaries and state management.
- Test keyboard navigation, focus states, and color contrast.
