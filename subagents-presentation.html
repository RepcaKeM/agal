1. Ewolucja koncepcji: Od Presetów do Agentów
Dlaczego subagenci i co to zmienia w codziennej pracy?

Dotychczas agal zarządzał presetami narzędziowymi (skille + serwery MCP), zmniejszając szum w kontekście. Nowa koncepcja idzie o krok dalej: zamiast jednego monolitycznego agenta z torbą narzędzi, zyskujesz wyspecjalizowanych subagentów dedykowanych do wąskich zadań.

📋 Presety (Pozostają w aplikacji)

Statyczny zestaw skilli i MCP dołączany do głównego agenta.

  • Wszystkie narzędzia widoczne od razu w sesji głównej
  • Jeden duży prompt i wyższe ryzyko halucynacji
  • Idealne do prostych prac lub stałych zestawów fullstack

🤖 Subagenci (Nowa oś projektu)

Wąsko wyspecjalizowani pomocnicy wywoływani zadaniowo.

  • Czysty kontekst: Subagent dostaje tylko narzędzia i instrukcję pod swoją rolę
  • Ścisłe uprawnienia: Read-only dla audytu i researchu, write tylko dla UI
  • Delegacja: Główny agent sam wie, kiedy przekazać zadanie pomocnikowi
Złota zasada izolacji: Wszystkie zmiany tworzone przez subagenta dzieją się wyłącznie lokalnie w Twoim projekcie. Zero globalnych modyfikacji systemowych, pełne czyszczenie przez agal unprepare.

2. Anatomia Subagenta (Format AGENT.md)
Jak definiujemy specjalizację i narzędzia w folderze Subagents/

Każdy subagent mieszka w katalogu Subagents/<nazwa>/AGENT.md (analogicznie do Skills/). Łączy metadane YAML z systemową instrukcją zachowania: 

---
name: researcher
description: >-
  Deep codebase exploration and docs queries.
  Use when user asks for deep research or docs.
model: inherit  # inherit | sonnet | opus | haiku
permissions:
  edit_files: false   # Read-only!
  run_commands: true
skills:
  - context7-docs
  - find-docs
mcp:
  - context7
---
# System Prompt
You are a dedicated research subagent.
Your role is strictly investigative...

🧠 Kluczowe pola definicji:

  • name: Unikalny identyfikator (musi odpowiadać nazwie folderu).
  • description: Krótki opis z regułą wywołania Use when ….
  • permissions: Flagi edit_files i run_commands (domyślnie true).
  • skills & mcp: Zależności, które agal automatycznie doinstaluje do projektu.
  • body: Precyzyjny prompt systemowy definiujący zachowanie pomocnika.

🛡️ Bezpieczeństwo i walidacja:

Agal automatycznie sprawdza poprawność nagłówka YAML, odrzuca uszkodzone pliki i ostrzega o brakujących skillach bez przerywania pracy.

3. Natywne Adaptery (4 Środowiska)
Jedno polecenie generuje pliki dla każdego CLI i IDE bez kompromisów

Polecenie agal subagent add <nazwa> materializuje definicję w formatach w 100% natywnych dla każdego narzędzia:

Ścieżka: .claude/agents/researcher.md

Wykorzystuje natywny mechanizm subagentów Claude Code:

---
name: researcher
description: Deep codebase exploration...
model: inherit
skills: [context7-docs, find-docs]
mcpServers: [context7]
disallowedTools: [Edit, Write, NotebookEdit]  # Narzucony zakaz edycji!
---
You are a dedicated research subagent...

Ścieżka: .cursor/agents/researcher.md

Format reguł i person agenta dla Cursor Composer / Agent:

---
name: researcher
description: Deep codebase exploration...
model: inherit
readonly: true  # Automatyczne zablokowanie edycji plików w Cursorze!
---
You are a dedicated research subagent...

Ścieżka: .opencode/agents/researcher.md

Format subagentów OpenCode z precyzyjną mapą uprawnień:

---
description: Deep codebase exploration...
mode: subagent
permission:
  edit: deny    # Odmowa edycji
  bash: allow   # Zgoda na komendy terminala
---
You are a dedicated research subagent...

Ścieżka: .agents/agents/researcher/agent.md

Format Antigravity Agent z przypisaniem skilli z .agents/skills/:

---
name: researcher
description: Deep codebase exploration...
subagent: true
mainAgent: false
model: inherit
skills:
  - skills/context7-docs
  - skills/find-docs
tools: [view_file, grep_search, run_command]  # Bez narzędzi edycji!
---
You are a dedicated research subagent...
💡 Czyste unmaterialize: Przy usunięciu subagenta agal usuwa plik i rekursywnie sprząta puste foldery nadrzędne (np. usuwa .cursor/agents, jeśli nic innego tam nie ma), nie naruszając innych plików projektu.

4. Gotowy Starter Pack Subagentów
Trzy zdefiniowane role dostarczane prosto z repozytorium

🔍 researcher

Read-Only Terminal OK

Cel: Głęboka analiza kodu, przeszukiwanie dokumentacji i kwerendy w bazach wiedzy.

  • Skille: context7-docs, find-docs
  • MCP: context7
  • Ograniczenie: Całkowity zakaz modyfikacji plików

🛡️ auditor

Read-Only Terminal OK

Cel: Niezależny przegląd kodu pod kątem bezpieczeństwa, reguł architektury i jakości.

  • Skille: requesting-code-review, verification-before-completion
  • MCP: brak
  • Ograniczenie: Zgłasza uwagi z numerami linii, nie dotyka implementacji

🎨 ui-specialist

Read-Write Terminal OK

Cel: Projektowanie i wdrażanie interfejsów, komponentów CSS/HTML oraz dostępności (a11y).

  • Skille: a11y-debugging
  • MCP: brak
  • Uprawnienia: Pełny dostęp do zapisu plików i testów komponentów

Tworzenie własnych subagentów:

Możesz wygenerować szablon nowego subagenta jednym poleceniem: agal subagent create devops. Utworzy to plik Subagents/devops/AGENT.md, który możesz dostosować do własnych potrzeb.

5. Komendy CLI i Zarządzanie Zależnościami
Reference Counting: Usuwasz agenta, a współdzielone narzędzia zostają bezpieczne
Polecenie Działanie Przykład
agal subagent list Wyświetla listę wszystkich dostępnych subagentów wraz z opisem agal subagent list
agal subagent add [NAME...] Instaluje agentów w projekcie. Bez argumentów otwiera menu wyboru fzf agal subagent add researcher auditor
agal subagent remove NAME... Usuwa adaptery i sprząta zależności, które nie są już nikomu potrzebne agal subagent remove researcher
agal subagent create NAME Generuje nowy szablon AGENT.md w folderze Subagents/ agal subagent create performance-tester
agal unprepare Całkowicie czyści projekt: usuwa subagentów, presety, adaptery i pliki stanu agal unprepare

🛡️ Reference Counting w akcji

Załóżmy, że instalujesz subagenta researcher (wymaga skilla find-docs) oraz preset fullstack (który również używa find-docs).

Gdy uruchomisz agal subagent remove researcher, agal usunie pliki adaptera, ale zachowa skill find-docs, bo wie, że preset wciąż z niego korzysta!

  "subagents": {

    }
  },
  "subagent_owned": {
    "skills": ["context7-docs"]

Jak zacząć korzystać z subagentów już teraz?

  1. W swoim projekcie uruchom: agal subagent add researcher auditor
  2. Włącz swoje ulubione narzędzie:
    • W Claude Code wpisz /agents i zobacz swoich pomocników
    • W OpenCode użyj wzmianki @researcher
    • W Cursorze czy Antigravity agenci sami zobaczą pliki definicji i delegują zadania
  3. Gdy skończysz zadanie w projekcie: agal unprepare usunie całą konfigurację bez śladu!
